# Сколько текста влезает в баннер

Гайд для копирайтеров по лимитам текста в главном баннере мобильной версии vamprivet.ru.

Внутри — форма проверки: вставляете заголовок и описание и сразу видите, влезает текст или обрежется.
Форма ломает строки теми же метриками шрифта и той же шириной колонки, что и сайт, поэтому её ответ
совпадает с тем, что увидит пользователь на телефоне.

## Что в гайде

- проверка своего текста на трёх ширинах экрана — 320, 375 и 414 px;
- рабочие лимиты: 20 символов на заголовок, 70 на описание, 13 на самое длинное слово;
- почему колонка узкая и что происходит с текстом, который не влез;
- две ловушки: длинные слова и неразрывные пробелы;
- три живых баннера и их сокращённые версии.

## Как открыть

Файл самодостаточный, без зависимостей — можно просто открыть `index.html` в браузере.

Чтобы получить ссылку для команды, включите GitHub Pages:
Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root`.

## Откуда цифры

Все замеры сняты с живого vamprivet.ru при ширине экрана 320–414 px:
ширина текстовой колонки, кегли, интерлиньяж и ширина каждой буквы шрифта Gotham.
